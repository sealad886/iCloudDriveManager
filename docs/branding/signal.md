# Signal

Status: **proposed; awaiting generated-board review and user selection**.

## Identity

A precise folded-file shape is crossed by one diagonal synchronization path. The fold makes the mark recognizable as a file utility; the path conveys exchange without promising a particular transfer order. Use a strong outer silhouette and one deliberate cutout rather than a cluster of small arrows or technical badges.

The wordmark is **iCloud Drive Manager**, in the native system typeface at semibold weight. Use a direct, clean setting with standard letterforms. A candidate supporting line is “Know what’s moving.” It is descriptive, not a claim of complete system-queue visibility.

Calculated sRGB contrast: white on primary **6.30:1**; primary on periwinkle **4.91:1**; graphite on periwinkle **12.85:1**; dark accent on graphite **8.91:1**. These describe solid swatches; native materials, disabled controls, and tinted appearances require rendered inspection.

## Logo rules

- Clear space: at least one quarter of the mark height on every side.
- Minimum mark: 16 pixels in the simplified monochrome version; 24 pixels when the fold is visible.
- Primary lockup: 200 pixels wide or larger. Use a two-line wordmark or accessible mark-only treatment in narrow native surfaces.
- Light version: cobalt mark and graphite wordmark on a suitable light surface.
- Dark version: periwinkle-accent mark and the native primary text color.
- Never place text inside the file, duplicate the path to create a busy network motif, or use the brand path as a progress percentage.

## Native application

Use a 28-point mark in the sidebar and a 64–88-point mark in onboarding. Cobalt accents primary actions and selected brand details while native selection, focus, and status states remain system-controlled. Keep the sidebar's standard material and the file table's native density.

Typography is system default: 26–28-point semibold headers, 13–15-point body copy, and 11–12-point supporting labels. Monospaced digits are reserved for counts, sizes, and progress. Avoid condensed display fonts and decorative tracking in utility controls.

## Icon Composer direction

Use a cobalt background, an independent file body, and a separate diagonal-path foreground. Keep the fold as part of the file layer rather than baking multiple shadows into it. Apply restrained materials so the path stays distinct at Dock size. Dark appearance uses graphite with a pale path; tinted appearance must preserve the fold and diagonal negative space.

For the 16–32-pixel fallback, simplify the fold and remove secondary lighting. The menu-bar version is a single-color template silhouette. Preserve the editable `.icon` source and original layers; export a macOS 15 `.icns` fallback rather than relying on new icon rendering alone.
